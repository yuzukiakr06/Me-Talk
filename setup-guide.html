利用者は me.mirai-vps.jp にアクセス → Cloudflare がトンネル経由で Discloud 上の Me Talk（ポート8000）につなぎます。
ポイント：「トンネルのトークン」と「つなぎ先ポート(8000)」の2つを合わせるだけです。

PART 1：config.json を作る

ZIP の中の config.json.example をコピーして config.json に名前を変え、中身を書き換えます。

最小構成（まずこれで起動できます）

{
  "SITE_NAME": "Me Talk",
  "BASE_URL": "https://me.mirai-vps.jp",
  "DATABASE_URL": "sqlite:///./data/mirai_chat.db",
  "APP_PORT": "8000",          // ← cloudflaredのつなぎ先と合わせる
  "CLOUDFLARED_TOKEN": "eyJh...（PART2で取得）",
  "HIDE_DEV_CODES": "0"       // 0=確認コードをログに出す(テスト用)
}
APP_PORT を 8000 にしておくと、アプリは必ず 8000 番で起動します。 Cloudflare 側のつなぎ先も 8000 にすればピッタリ合います（ここがズレると 502 になります）。

各項目の意味

項目何を書く空でもいい？
SITE_NAMEアプリ名—
BASE_URL公開URL https://me.mirai-vps.jp—
APP_PORT8000 固定推奨—
CLOUDFLARED_TOKENトンネルのトークン（PART2）空だと非公開で起動
SMTP_*メール送信設定◎ 空でOK（コードはログに出る）
GOOGLE_*Googleログイン◎ 空でOK（ボタン無効になるだけ）
ANTHROPIC_API_KEYMirei(AI)のAPIキー◎ 空でOK（AIだけ無効）
注意：Discloud に手動アップロードする ZIP には config.json を必ず入れてください。 （.discloudignore に config.json があるのは Git 用の除外設定で、手動アップの ZIP には含めて構いません。含めないと秘密情報が読み込まれません）

PART 2：Cloudflare トンネルを作る

MIRAI ID と同じ「トークン方式」です。Cloudflare のダッシュボードで Me Talk 用のトンネルを1つ作ります。

1
Zero Trust ダッシュボードを開く
one.dash.cloudflare.com → 左メニュー Networks → Tunnels
2
「Create a tunnel」を押す
タイプは Cloudflared を選択 → 名前を me-talk にして保存
3
トークンをコピーする
「Install and run a connector」の画面に、cloudflared ... run --token eyJ... という長い文字列が出ます。この eyJ で始まる部分（トークン）だけをコピー。
→ これを config.json の CLOUDFLARED_TOKEN に貼ります。
4
Public Hostname を設定する（ここが一番大事）
トンネルの Public Hostname タブ → Add a public hostname
Public Hostname の入力内容
項目入れる値
Subdomainme
Domainmirai-vps.jp
Path（空のまま）
TypeHTTP
URLlocalhost:8000 config.json の APP_PORT と同じ数字
ここが合っていないと 502 エラーになります。
config.json の APP_PORT と、この localhost:8000 の数字を必ず一致させてください。
5
WebSocket を有効にする（チャットのリアルタイム通信に必要）
同じ Public Hostname の Additional application settings → TLS や HTTP Settings の中に WebSocket のトグルがあれば ON に。
※ Cloudflare は通常 WebSocket が既定で有効ですが、念のため確認。アカウント設定 → Network → WebSockets も ON。

PART 3：2つの数字を合わせる（最重要）

config.json

localhost:8000

この 8000 が両方で一致していれば、トンネルは正しくつながります。

PART 4：アップして確認

1
config.json を入れた me-talk フォルダを ZIP にする
2
Discloud にアップロード（MIRAI ID と同じ要領）
3
ログに次が出れば成功：
INFO: Application startup complete.
INFO: Uvicorn running on http://0.0.0.0:8000
[cloudflared] トンネルを起動しました
4
ブラウザで https://me.mirai-vps.jp/app を開く → 起動画面が出れば公開成功！
登録時の確認コードについて：SMTP を設定していない場合、メールは飛びませんが、 確認コードは Discloud のログに [mail] ... 確認コード(register): 123456 の形で出ます。 それを入力すれば登録できます（テスト時はこれでOK）。
