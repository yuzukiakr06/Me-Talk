Me Talk 準備ガイド
Googleログイン と ロボット確認(Turnstile) のキー取得手順
この作業でやること: 2つのサービスで「鍵」を取ってくるだけです。取れたら私に渡していただければ、実装は私がやります。どちらも無料で、合計15〜20分ほどです。

A. Googleログイン (Google Cloud Console)

Googleアカウントでログインできるようにします。「クライアントID」と「クライアントシークレット」の2つを取得します。

1
Google Cloud Console を開く
console.cloud.google.com にGoogleアカウントでログイン
2
プロジェクトを作る
画面上部のプロジェクト選択 → 「新しいプロジェクト」→ 名前を Me Talk にして作成。作成後、そのプロジェクトが選択された状態にします。
3
Google Auth Platform を開く
上部の検索窓で Google Auth Platform と検索、または console.cloud.google.com/auth/overview へ直接アクセス
4
アプリ情報を入力
アプリ名に Me Talk、サポートメールにご自分のメールアドレスを入力して次へ。
対象(ユーザーの種類)は 「外部」 を選びます。
5
クライアントを作成
左メニューの 「クライアント」 → 「クライアントを作成」
アプリケーションの種類 = ウェブ アプリケーション
名前 = Me Talk Web
6
URIを2種類 登録する（ここが一番大事）
項目入れる値
承認済みの
JavaScript生成元		https://me.mirai-vps.jp
承認済みの
リダイレクトURI		https://me.mirai-vps.jp/api/auth/google/callback
リダイレクトURIは1文字でも違うとエラーになります。末尾のスラッシュも付けないでください。上の値をそのままコピーするのが確実です。
7
作成 → 2つの値をコピー
作成すると クライアントID（...apps.googleusercontent.com で終わる長い文字列）と クライアントシークレット（GOCSPX- で始まる文字列）が表示されます。
この2つを控えてください。
テストユーザーについて。公開設定が「テスト中」のままだと、登録したテストユーザーしかログインできません。誰でも使えるようにするには、Google Auth Platform の「対象」画面で 「公開」(本番環境に push) にしてください。
なお、メールアドレスなど基本情報だけを使う場合はGoogleの審査は不要です。

B. ロボット確認 (Cloudflare Turnstile)

自動登録botを防ぎます。Cloudflare Turnstile を使います。すでにCloudflareをお使いなので相性がよく、無料で、reCAPTCHAのような「信号機を選ぶ」画面がほぼ出ません(自動で通ります)。

1
Cloudflareダッシュボードを開く
dash.cloudflare.com にログイン（トンネルで使っているアカウントでOK）
2
Turnstile を開く
左メニューから 「Turnstile」 を選択 → 「Add widget」（ウィジェットを追加）
3
ウィジェットの設定
項目入れる値
Widget name
(名前)		Me Talk
Hostname
(ドメイン)		me.mirai-vps.jp
Widget ModeManaged（おすすめ・自動判定）
4
作成 → 2つのキーをコピー
作成すると Site Key（公開用・0x4... のような文字列）と Secret Key（秘密・サーバー用）が表示されます。
Turnstileのキーは後から何度でも見返せます（Manage widget から）。
Site Key は画面に出るので公開されても問題ありません。Secret Key はパスワードと同じなので、他人に見せないでください。

C. 取得したら私に渡す

4つの値が揃ったら、次の形で教えてください。config.json に設定して実装します。

GOOGLE_CLIENT_ID     = 123456789-xxxxx.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET = GOCSPX-xxxxxxxxxxxxx
TURNSTILE_SITE_KEY   = 0x4AAAAAAxxxxxxxxx
TURNSTILE_SECRET_KEY = 0x4AAAAAAxxxxxxxxxxxxxxxxx
安全のために。シークレット類はこのチャットに貼っていただいても構いませんが、心配であれば「取得できました」とだけ伝えていただき、ご自身で config.json に貼る方法でも大丈夫です。その場合は設定する場所をお伝えします。

チェックリスト

Google: プロジェクト作成 → Auth Platform でアプリ情報入力(外部)
Google: ウェブアプリのクライアント作成
Google: JavaScript生成元 と リダイレクトURI を登録
Google: クライアントID と シークレットを控えた
Google: 公開設定を「公開」にした(誰でも使えるように)
Turnstile: ウィジェット作成(Managed / me.mirai-vps.jp)
Turnstile: Site Key と Secret Key を控えた

実装後にできること

機能内容
Googleログインログイン画面に「Googleでログイン」ボタンを追加。初回はMe Talkのユーザー名を決めてもらう流れにします。
ロボット確認新規登録時（と必要ならログイン時）に自動でbot判定。ほとんどの人は何も操作せず通過します。
